# David Muñoz Olaya — Portfolio

Starter portfolio built with semantic HTML, CSS and vanilla JavaScript. No frameworks and no build step.

## Run locally
Open `index.html` in a browser. For a more realistic local setup, use any static file server (for example VS Code Live Server); no package installation is required.

## First customisations
1. Replace `hello@example.com` with your professional email.
2. Replace the generic GitHub and LinkedIn URLs with your real profile URLs.
3. Review the bio and only keep statements that accurately represent your experience.
4. Replace the AquaReminder abstract artwork with real app screenshots when available.
5. Confirm the technology list matches what you actually use in AquaReminder.
6. Add project detail pages only when you have enough content to make each case study useful.
7. Add canonical URLs, `hreflang`, a sitemap and per-language URLs before focusing on international SEO.

## Structure
- `index.html`: semantic page content
- `css/styles.css`: design tokens, layout, components, animation and responsive rules
- `js/main.js`: bilingual copy, mobile navigation, reveal animations
- `assets/favicon.svg`: simple vector favicon

## Notes
- Spanish is the default language; the toggle switches to English.
- Language preference is saved in localStorage when available.
- Animations respect `prefers-reduced-motion`.
- Contact currently uses `mailto:`. There is no backend or form submission.
- Project details and claims are placeholders and should be validated before publishing.
